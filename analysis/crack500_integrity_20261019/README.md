# Crack500 数据来源、实际目录与完整性核验

核验日期：2026-10-19；完整扫描回执时间为 14:03:23（UTC+8）。这是数据文件核验，没有运行模型推理、计算 test 性能或调整训练划分。

## 结论

当前使用的是 **Crack500 的完整公开裁剪分割基准，共 3,368 对图像/标签**。本机数量、三份划分清单与本地保留的原始发布包一致；逐文件检查没有发现缺失、解码失败、图像标签尺寸不匹配或前景标签变化。原包图像字节全部一致；标签 PNG 字节编码不同，但标签像素均为 0/1，前景逐像素一致。

这个结论针对裁剪基准。它不表示已经验证本机拥有全部 500 张高分辨率原图，也不表示已经证明所有划分完全源图互斥。

## 是哪个公开数据集

[原作者仓库：fyangneil/pavement-crack-detection](https://github.com/fyangneil/pavement-crack-detection)发布 Crack500 并提供数据下载入口；[原作者论文 IV-B1 节](https://arxiv.org/html/1901.06340)说明，原始 500 张图像按 250/50/200 划分，裁剪筛选后为 1,896/348/1,124 对。我们使用的是后者。Crack500 与 DeepCrack、CFD 是不同数据集。

## 完整性与划分风险

- 三份清单的顺序、条目集合与本地原始包完全一致，没有漏项、重复条目或目录多余文件。
- 全部 3,368 张训练用图像与原包 SHA256 一致，3,368 张标签的前景逐像素一致。
- 原件的 6,736 个文件长度与 CRC 均匹配本地三个 crop ZIP 的记录；分开存放的副本也已核对。
- 全部图像和标签已解码，尺寸逐对一致。尺寸有 640×360、360×640、648×484，不能假定每张都是同一尺寸。
- 跨划分没有相同图像文件 SHA256；但按去掉最后两个裁剪坐标的文件名前缀推断，train/test 有 5 个重叠前缀，val/test 有 1 个。重叠前缀已经存在于本地原始发布包清单中。
- 对跨划分同名的 4 对裁块额外比较了 RGB 像素，均非逐像素相同。**文件名前缀只是疑似同源线索，不足以单独证明重复原图或数据泄漏**；仍需结合原始照片、方向和裁剪映射做源图级确认。当前保持公开基准划分，后续泛化评估应保留 source-frame-disjoint 复核。

因此，“裁剪基准文件齐全”已通过核验；“所有样本完全独立”没有据此获得证明。没有为消除风险而临时改变正在使用的训练/验证/test 划分。

## 核验范围与复现

[audit.json](audit.json)记录数量、清单、图像尺寸、标签值、跨划分前缀及同名图像比较；[file_sha256.json](file_sha256.json)记录当前文件与本地原件的 SHA256；[verify_crack500.py](verify_crack500.py)可重跑核验（需要 NumPy、Pillow 及文中本地路径）。脚本只读取数据，输出仅写本目录。

公开标准数量已与原作者论文核对；文件内容比对对象是**本地保留的发布包及其 ZIP 校验记录**。本次没有重新下载远端约 2 GB 总包，也没有可用于远端逐字节认证的独立官方 SHA256 清单。数据本体不上传 GitHub，本报告与核验代码/回执随项目进度上传。

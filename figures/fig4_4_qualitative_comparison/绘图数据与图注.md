# Fig. 4-4 绘图数据与图注

本图使用 Crack500 验证集的四张真实图像，在完全相同的输入和人工标签上对比 SegFormer-B0、UAFM 和 PPContextModule。每个模型使用已有训练结果，不重新训练；未访问 Crack500 test。

## 图注

**中文：** 图 4-4 Crack500 验证集上的定性比较结果。每一行对应一种场景：细裂缝、阴影/低对比度、纹理密集路面和宽裂缝；每一列依次为原始图像、人工标签、SegFormer-B0、SegFormer-B0+UAFM 和 SegFormer-B0+PPContextModule 的预测掩膜。预测掩膜下方标出了该图像的裂缝 IoU。三种模型使用相同的冻结前验证协议进行官方推理，图中结果用于解释细裂缝保持、误检、漏检和宽度恢复的差异。

**English:** Fig. 4-4. Qualitative comparison on the Crack500 validation set. The rows show fine cracks, shadow/low-contrast cracks, dense-texture pavement, and wide cracks, respectively. The columns show the input image, ground-truth label, SegFormer-B0, SegFormer-B0+UAFM, and SegFormer-B0+PPContextModule predictions. The crack IoU for each image is listed below each prediction. All models were evaluated on the same images with the official validation preprocessing.

图中 PPContext 和 UAFM 是验证阶段受控消融结果；二者没有通过预设完整筛选门槛，因此该图用于误差解释，不代表最终模型已经优于基线。

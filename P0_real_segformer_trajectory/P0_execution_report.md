# P0 执行记录：真实 SegFormer Mask 替换模拟 Mask

日期：2026-10-14

## 目标

把原先的模拟掩膜替换为真实 SegFormer-B0 推理结果，并完成“图像 -> 掩膜 -> 骨架 -> 裂缝几何 -> 轨迹”的可审计链路。

## 已执行内容

1. 使用冻结的 Crack500 SegFormer-B0 权重对真实验证图像 `valcrop/20160222_080850_1281_361.jpg` 推理。
2. 对模型预测结果反变换回原图尺寸并保存原始二值掩膜。
3. 删除小于 8 px 的孤立连通域仅用于显示和轨迹提取，原始掩膜仍单独保留。
4. 用 `skimage.morphology.skeletonize` 得到单像素骨架。
5. 对最大骨架连通分量提取端点路径，用 B 样条进行离线平滑。
6. 用欧氏距离变换生成局部宽度图，用于裂缝图展示。
7. 生成一张含六个子图的论文实验图。

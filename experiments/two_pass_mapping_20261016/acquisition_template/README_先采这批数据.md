# 第一批采集说明

此目录是空模板，未填任何实测标定值，不可拿来驱动机器人。

1. 填 `hardware_information_to_fill.json`，未知项保留 null；拍摄机器人全貌、侧面和相机/XYZ/喷嘴安装关系，放 `hardware_photos`。
2. 使用实际工作相机和工作分辨率，先固定焦距/成像设置。准备平整硬底棋盘板；9×6内角点对应10×7方格。标定板SVG在上级 `opencv_calibration`，标称格长20 mm，打印后必须实测。
3. 采25–40张不同倾角、距离和画面位置的棋盘照片，放 `calibration/intrinsics_images`；另采约10张独立验证照片，放 `calibration/heldout_images`。相机可以固定，手动移动板子。
4. 记录棋盘横纵实际格长和测量方法到JSON/`calibration/images.csv`。保留原图，不先裁剪缩放。仅平移一个完全平行地面的棋盘不适合作为完整内参标定数据。
5. 首批处理完后，再采同地面平面的已知点照片，区分拟合点fit和独立检查点check。`ground_points.csv` 中原图若未去畸变，明确 `coordinate_image_version=raw_distorted`，由处理时统一转换。

第二批拍两条有重叠的扫描带：每条约8–15个停稳拍摄位置作为先导，实际数量按相机视场调整。把图放 `mapping_run_001/frames`；采集时刻填 `frames.csv`，同一时钟下的位姿填 `poses.csv`。没有位姿日志可以先用画面内已测量的控制点；此时不得填写猜测位姿。

坐标单位：地面和位姿用米，角度用弧度，四元数顺序qx,qy,qz,qw。模板只含字段，无默认有效坐标。指定同一场地原点、坐标轴和标记角点次序；marker四角不得无说明交换。

第一批无需出胶、无需让机器人自动扫完整场地。请把数据保存在该目录或告知真实数据目录，后续从内参和地面独立点验证开始。

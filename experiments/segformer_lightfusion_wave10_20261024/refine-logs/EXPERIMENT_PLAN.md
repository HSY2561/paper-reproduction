# SegFormer-B0 + Aligned：轻量多尺度融合波次10

## 目标

A0 在 C1、C2、C3、C4 对齐后仍做 `concat(4D) -> 1x1(4D, D)`。本波固定 MiT-B0、Aligned、输入增强、CE、AdamW、FP32、seed 42 和 18,000 iter，只替换这一步或改变解码宽度。目标是在 Crack500 验证集保持 A0 的裂缝 IoU/F1/mIoU，同时把参数进一步降低，优先寻找相对 A0 至少 1% 的减参候选。

## 候选登记

| 类别 | 候选 | 位置 | 预期 | 主要成本/风险 |
|---|---|---|---|---|
| 控制 | W96/W80/W64 | 整个融合宽度 | 建立精度-宽度曲线 | 细裂缝通道容量下降 |
| 加和 | Sum/Weighted/ChannelWeighted | 四路对齐特征 | 去除 512 通道拼接，保留各尺度 | 尺度信息相互抵消 |
| 分组 | Pair/Hierarchical/GatedPair | 低高层成对融合 | 用两次聚合保留层次关系 | 中间层互补不足 |
| 低秩 | LowRank32/16 | 512→r→D | 直接压缩大融合矩阵 | 信息瓶颈、边界变细 |
| 分支瓶颈 | Branch32/16 | 每路 D→r 后融合 | 保留分支身份，显著减参 | 低层细节压缩过度 |
| 空间轻量 | DWSum/SeparableSum | 加和后的空间混合 | 深度卷积恢复局部结构 | 额外算子可能增加延迟 |
| 宽度组合 | Sum96/LowRank96/DWSum96/Sum64/Branch64 | 轻量宽度+替换 | 探索 Pareto 前沿 | Recall 和边界 F1 可能下降 |

## 统一流程

每项顺序为 20 iter smoke、18,000 iter 正式训练、普通/EMA 精确验证 mIoU 选模、冻结 SHA256、官方 `val.py`、全 348 张验证图的全局混淆矩阵和零外延 2px 边界 F1、参数量和同机延迟。失败只记录真实退出码和日志，不填性能数字。筛选阶段禁止读取 test 和自建数据。

相对 A0 的主门槛为：mIoU、裂缝 IoU、F1 不低于 A0-0.002，Precision、Recall、边界 F1 不低于 A0-0.005；轻量门槛还要求参数量不超过 A0 的 99%。未同时满足精度和效率门槛的候选保留为负结果。最终只从验证集形成 Pareto 候选，再做多种子、六个原始公开模型和 test 统一评估，不能提前声称 SOTA。

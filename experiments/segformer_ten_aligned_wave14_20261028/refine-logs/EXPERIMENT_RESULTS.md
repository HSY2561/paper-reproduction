## 当前单 seed 排名与解释

- 裂缝 IoU 最高：**CoordinateAttention**，68.5898%；其次为 InceptionDWConv，68.3249%。
- mIoU 最高：**CoordinateAttention**，83.2019%。
- 2px 边界 F1 最高：**CoordinateAttention**，45.8213%。
- 半径≤1像素细线 Recall 最高：**WTConv**，49.5059%。

Coordinate Attention 在本轮单 seed 中同时给出最高裂缝 IoU、mIoU 和 BF1@2，且参数量为 3.690466M；它是当前最值得进入后续稳定性复核的候选。该判断仍是验证集 seed42 的筛选信号，不能替代 seed43/44 和统一 test。

LSKA 的细线 Recall(r≤1)最高，说明其对最细目标有较强信号，但其总体 IoU 和 mIoU 没有达到 Coordinate Attention；WTConv 的细线 Recall 也较高。Strip Pooling 的 BF1@2较高但区域 IoU偏低，不能仅凭边界指标选为最终模型。

## 证据与限制

每组的 checkpoint SHA256、config SHA256、普通/EMA选择记录、训练/验证/边界 exit 文件和完整混淆矩阵均保存在本工程 `results/`、`checkpoints/`、`logs/` 和 `provenance/` 下。边界 F1 使用内边界、精确欧氏距离≤1/2像素并聚合计数；细线 Recall 使用 GT 半径≤1像素分层；hard clDice 和骨架指标按同一独立脚本计算。

审计时发现原始 `results/queue_done.json` 的 `formal_jobs` 与 `successful18k` 字段仍为 8，而实际存在 10 个训练 exit 文件（均为 0）和 10 个已核验记录。原始回执未被改写；该计数差异已记录在 `provenance/queue_done_count_audit.json`，本报告的十行结果以逐组 verified 证据为准。

当前尚未进行 seed43/44、稳定同机延迟、峰值显存/FLOPs 和 test。下一步应先冻结最多两个验证集候选（建议 Coordinate Attention 与 LSKA 或 WTConv），再做多种子和资源复核；只有候选在多种子、参数与速度条件下仍有可信优势，才进入统一 test。

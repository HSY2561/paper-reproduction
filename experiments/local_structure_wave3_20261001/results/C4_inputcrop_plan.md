# C4 输入/裁剪单变量实验计划

- 基线：C0 BiSeNetV2，复用同一数据、seed=42、batch=4、FP32、18,000 iter、EMA、OHEM/Dice、end_lr=0。
- 唯一变化：ResizeStepScaling 从 0.5–2.0 改为 0.75–1.25。
- 保持不变：400×400 RandomPaddingCrop、翻转、颜色扰动、模型结构、损失、优化器、学习率和验证选模。
- 目的：减少大尺度随机裁剪导致的空裂缝样本和主体截断，验证输入/裁剪是否是当前瓶颈。
- 选择门槛：相对 C0，裂缝 IoU 至少 +0.005、F1 至少 +0.003、Recall 下降不超过 0.005；同时记录边界 F1、空预测、细/宽裂缝分层表现。
- test 集在候选筛选期间封存。

# AW 精度诊断与单变量修正报告（2026-11-12）

## 1. 本轮目标和结论

本轮固定 SegFormer-B0 + Aligned + 标准 Haar 小波 WTConv，不叠加任何新模块，只排查并修正 Precision 偏低的问题。完成了两项受控实验：

1. **训练侧单变量**：将交叉熵权重改为 `[background=1.10, crack=1.0]`，其他结构、数据、增强、优化器、预算和随机种子全部保持不变。
2. **推理侧诊断**：在完整验证集上扫描前景阈值，得到 `0.525` 的精度优先策略；阈值没有参与模型训练，也没有用 test 反向选阈值。

加权 CE 已完成 18,000 iter，真实 exit 0。按精确 val mIoU 规则选择普通 checkpoint。它把 test Precision 从原始 AW 的 **71.143%** 提升到 **73.159%**，同时 F1、裂缝 IoU、mIoU 和 BF1@2 小幅提高；代价是 Recall 和极细裂缝连通性指标略降。使用验证集确定的 0.525 阈值后，test Precision 达到 **74.401%**，且仍高于历史 SegFormer-B0，但 Recall 和细线召回进一步下降。因此 0.525 应作为精度优先部署策略，不能写成结构全面提升。

## 2. 协议审计

- 数据：Crack500 注册 train/val/test 清单；没有删样本、改验证集或读取自建集。
- seed：42；FP32；batch size=4；18,000 iter。
- 优化：AdamW，初始学习率 `6e-5`，PolynomialDecay 到 0，weight decay=0.01。
- EMA：开启；普通和 EMA 均做精确 val，按最高 val mIoU 选模，test 在冻结后才评估。
- 增强：ResizeStepScaling(0.75–1.25)、RandomPaddingCrop(400×400)、水平翻转、RandomDistort、Normalize。
- 结构：SegFormer-B0 + Aligned + 标准 Haar DWT/IWT WTConv，levels=1，kernel=3。
- 唯一训练变量：CrossEntropyLoss 权重 `[1.10, 1.0]`。参数量和推理结构不变。

相对原始 AW，背景加权 CE 将 test FP 从 **4,475,955** 降至 **3,969,559**，下降约 **11.3%**；FN 从 **3,442,333** 增至 **3,657,802**。这说明 Precision 的改善主要来自抑制背景误检，而不是同时减少漏检。

相对历史 SegFormer-B0，精度优先策略（加权 CE + 阈值0.525）的变化为：Precision **+1.510**、Recall **+0.496**、F1 **+0.997**、裂缝 IoU **+1.240**、mIoU **+0.687** 个百分点。由于历史基线与当前 AW 的训练记录并非同一轮重训，这些差值只能作为参考，不能写成严格公平的 SOTA 结论。

## 4. 原因诊断

### 4.1 Precision 低的直接证据是 FP 偏多

原始 AW 在 test 上 Recall 较高，但 FP 达到 4.48M。WTConv 的高频子带和 Aligned 的空间对齐会增强边缘响应，阴影、纹理和路面细小结构可能被激活，因此出现“召回较好、精度偏低”的方向。背景权重 1.10 后 FP 明显下降、FN 上升，支持这一诊断。

### 4.2 普通和 EMA 是精度-区域折中

加权 CE 的 val 结果：普通 mIoU **82.707%**，EMA mIoU **82.628%**，所以按固定规则选择普通 checkpoint。EMA Precision 更高（82.252% vs 80.993%），但 mIoU 和 Recall 更低；不能因为 Precision 单项更高而绕过冻结规则。

### 4.3 阈值是可解释的精度旋钮

加权 CE 的 val 扫描中，阈值 0.525 的 Precision 为 **82.165%**、mIoU 为 **82.625%**；相对 0.5，Precision 提高而总体区域指标只小幅下降。将同一阈值用于 test 后得到 74.401% Precision。该阈值来自 val 诊断，不应继续根据 test 最优点调参。

### 4.4 细裂缝仍是瓶颈

原始 AW test 的半径 `r≤1` 细线 Recall 约 **41.97%**，加权 CE 阈值 0.5 约 **39.82%**，说明抑制 FP 的代价主要落在极细裂缝和边界附近。当前修正解决的是背景误检，不是细裂缝连续性问题。

## 5. 建议的使用方式

- 机器人更怕误喷、优先减少假阳性：使用加权 CE checkpoint + `threshold=0.525`，并在独立现场数据上再次校准阈值。
- 更重视裂缝连续性和极细裂缝召回：使用加权 CE checkpoint + `threshold=0.5`；不要使用 0.525 作为默认阈值。
- 论文主表应同时注明模型结构、损失权重和推理阈值，避免把阈值带来的 Precision 变化误写成结构贡献。
- 不建议继续叠加模块。若还要做一轮，只做预注册的背景权重单变量（例如 1.05/1.10/1.15），保留完整验证集和相同冻结规则。

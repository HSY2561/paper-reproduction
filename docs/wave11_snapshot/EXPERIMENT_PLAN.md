## 2. 核心五行及固定内容

“固定压缩骨干”指 E0–E3 使用**相同结构、相同通道映射、相同初始化规则**，并不冻结骨干权重；四组仍端到端训练。

| 组别 | 骨干 | 解码路径 | M2 | 比较目的 |
| --- | --- | --- | --- | --- |
| R0 / 当前A0 | 原MiT-B0 | 原A0 width128＋Aligned | 关 | 总对照，量化压缩与最终净收益 |
| E0 | MiT-B0-S4FFN768 | 原A0解码器 | 关 | 四格共同母体 |
| E1 | 同E0 | M1轻量多尺度解码器 | 关 | M1独立贡献 |
| E2 | 同E0 | 原A0解码器 | 开 | M2独立贡献 |
| E3 | 同E0 | M1 | 开 | 联合收益与交互 |

F08只作额外的既有参考行，不能改变 E0 母体、门槛或按 test 反选。除骨干固定压缩及表中开关外，不同时修改 loss、输入、增强、训练预算、后处理或选模规则。

## 3. 固定压缩骨干与公平初始化

### 3.1 压缩范围

只把 S4 的两个 Mix-FFN 隐层从1024压到768，mlp_ratios 从[4,4,4,4]改为[4,4,4,3]。四阶段输出仍为32/64/160/256，attention、深度、S1–S3、LayerNorm及残差出口不改。原骨干3,319,392，压缩后3,051,616，CPU构造核验减少267,776。S4分辨率较低，参数降幅不能直接推断延迟降幅。

本地 B0 工厂硬编码 mlp_ratios，不能直接在 YAML 再传同名参数，真实 CPU 调用会报 duplicate keyword。后续在新隔离源码里命名明确的构造路径，原 B0 不改；名称不得冒充官方原始 MiT-B0。

### 3.2 ImageNet初始化与通道选择

共同原始 ImageNet 文件 SHA256：
211e15d5157b8d48b1931102c40094da0b578de1c153c5706360f7ad561a774e。

只利用该权重决定裁剪，不根据 train/val/test 分数挑索引，也不从已训练 A0/F08 微调起步。每个S4 block独立固定一次768个通道：

- a_j = fc1权重第j列绝对值均值＋fc1.bias[j]绝对值。
- d_j = 第j个depthwise核绝对值均值＋其bias绝对值。
- o_j = fc2权重第j行绝对值均值。
- score_j = (a_j/(mean(a)+1e-12)＋d_j/(mean(d)+1e-12)＋o_j/(mean(o)+1e-12))/3。
- 以 score 降序、原通道索引升序打破并列，取768，再按原索引升序存储。运算CPU float64，保存分数、索引、派生权重及SHA；四组、三个seed共享同一映射，不形成搜索轴。

本地是 Paddle Linear 的[in,out]排列，必须联动：
fc1.weight[:,I]、fc1.bias[I]、DW.weight[I,:,:,:]、DW.bias[I]、fc2.weight[I,:]；fc2.bias不裁。所有未改张量逐项bitwise继承，加载键/形状全记账，不静默跳过。

实现前置验收：eval/dropout关闭下，压缩FFN与原FFN仅保留相同hidden通道的遮罩版本，在固定输入上误差应满足atol=1e-5、rtol=1e-5；这不是要求与原完整1024通道FFN输出完全一致。

### 3.3 随机性控制

同seed不保证同初始化：新增模块会改变随机数消耗。每seed分别保存并回灌共享初始化：

- E0/E2共享原A0头；E1/E3共享M1头；四组共享骨干及相同形状的分类器初始张量。
- E2/E3共享M2初始张量与alpha=0.1。
- 新层按“组件名＋seed”的固定映射产生，构造顺序不决定共享权重。
- 分离记录初始化、dropout/DropPath、数据排列和增强随机流。训练前统一重设数据种子；预存每seed的数据顺序/增强重放清单或等价可审计机制，核对四组最初批次。BN运行状态单独登记。
- 不支持完整RNG/采样/EMA恢复时，中断后另建完整运行，不拼接不连续日志。

R0三seed在相同初始化、数据/增强/loss/预算及后端复现通过后复用。协议中的单一A0 checkpoint SHA只标识seed42的全348图复现见证，不是三seed共同SHA；S1须登记逐seed的config、init、checkpoint SHA及数据/后端证据索引。该逐seed核验目前待执行，缺失者先作历史参考，需补控时另登记，不能默认已匹配。新压缩权重本来不同，不能把 R0−E0 全归因于解码器；共同压缩条件内的四格比较才隔离 M1/M2。

## 4. M1：低分辨率轻量多尺度解码器

功能：将主要深层融合留在1/8尺度，以窄语义分支对齐到C1，避免四路128通道先全部恢复到1/4后拼接。它是**整体解码器替换**，不是在旧512→128融合后再加一层。四格只能验证整体 M1 的净效应。

400×400输入时：C1=32×100×100，C2=64×50×50，C3=160×25×25，C4=256×13×13。所有恢复使用实际目标shape，不能固定四倍放大C4。

固定结构：

1. 原生C1经1×1 Conv-BN-ReLU，32→128；原生C2/C3/C4各经1×1 CBR，64/160/256→32。
2. C3/C4双线性恢复至C2实际shape，按[C2,C3,C4]顺序拼接96→64 CBR，得到1/8语义特征。
3. 窄Aligned：low128、high64分别1×1投影到32；high投影恢复到C1后与low投影按官方顺序拼接，3×3预测2通道flow。warp源为**仍位于C2尺度的high64**，不是已放大的high64；输出64通道C1尺度语义。
4. 将[C1投影128，warped语义64]拼接192→128 CBR，输出F。
5. M2若开启则接在F后；否则恒等。之后沿用Dropout2D(0.1)、128→2分类及官方输出恢复。

除分类器外Conv bias=False，分类器bias=True。CBR均沿用原PaddleSeg BN配置。四个投影明确采用CBR，不能为了凑参考预算改为Linear。

官方 sfnet.AlignedModule 要求low/high同通道，不直接支持128/64；后续需隔离适配两个输入投影，保留已审计的flow/warp算法。它不是“现有YAML配置一下就已可用”。

预期收益是压缩融合头和高分辨率激活、保留跨尺度语义；风险是低分辨率先融合漏掉细线、通道瓶颈损伤Recall、grid_sample实际更慢。不能提前承诺阴影/落叶假阳性已改善。

## 5. M2：语义门控浅层细节恢复

输入为原生C1（32通道）和任何解码器的F（128通道、C1尺度）；E2/E3用完全同一接口和实现，不依赖M1内部特征。

固定定义：

- D=CBR1×1(C1,32→16)，S=CBR1×1(F,128→16)。
- g=sigmoid(Conv1×1([D,S],32→1,bias=True))，空间门控，广播到128通道。
- R=ConvBN1×1(DW-CBR3×3(D),16→128)，末端不加ReLU，允许正负细节残差。
- F_out=F＋alpha×g×R；alpha为单个可学习标量、初值0.1，不根据val扫描初值。
- D投影共享用于gate和R，不能重复实例化；不detach，不计算后丢弃；关闭M2时完全恒等。

这是使用标准算子与门控思路的新组合假设，受到形状/语义信息分离工作的启发，**不等于直接复现完整GSCNN**。首轮没有边界监督或拓扑loss，不能提前称已保持拓扑。

预期收益为已有语义区域附近的细线、边界和端点恢复；成本为高分辨率16通道分支与额外激活，风险为浅层纹理/阴影的假阳性、门控饱和、延迟上升。配套检查gate分布、alpha变化、分支梯度、FP/FN空间分布；这些用于解释，不按结果重调结构。

## 8. 评价：区域、边界、细线、连接性、效率

### 8.1 主评价与逐图归因

主决策为全部348图全局混淆矩阵得到的裂缝IoU；同时P/R/F1/mIoU。F1与前景IoU可互相换算，不是两份独立统计证据。输出全部逐图TP/FP/FN/TN、零重叠、空预测、负样本FP，不删除最差图。

主BF1延续3×3常量零外延腐蚀提取内边界、精确欧氏距离≤2px双向全局匹配；额外BF1@1px检查容差掩盖的偏移。空边界无虚构TP：空对空对全局匹配/总数均贡献0；单侧空产生对侧分母；全数据均空则BF1记NA，逐图另标空对空而不混入普通均值。

### 8.2 新增连接性诊断（只作评价，不改loss）

- 使用固定版本scikit-image的2D skeletonize/zhang，保存版本与二进制掩码哈希；argmax输出、不调阈值。
- hard clDice：Tprec=预测骨架落入GT mask的比例；Tsens=GT骨架落入预测mask的比例；两者调和平均。对全数据先累加各自分子分母再计算，同时保留逐图值；这是全局聚合硬骨架变体，不能冒充所有论文使用同一聚合。
- 单侧空为0，空对空逐图单列NA；全数据无骨架则NA。骨架不是边界，不能与BF1混用。
- GT掩码先四周补1像素常量0，再算精确欧氏距离变换并裁回原图；所有组相同，触及裁块边缘的骨架点另标记分报，避免把裁块外未知区域当成已知物理宽度。以GT骨架点处精确欧氏距离变换半径r分箱：r≤1、1<r≤2、r>2像素，统计落入预测mask的骨架Recall。它是像素半径代理，不是校准后的毫米宽度；还按GT前景占比/对比度分布报告，分箱仅依GT/输入固定，不按模型表现改标签。
- 固定24张val复核集：训练前依GT细线半径、图像对比度及文件名稳定排序分层选定，冻结清单；观察断点、端点缺失、错误桥接及纹理激活。总分后另导出各组最差图，不能把后选极值当无偏代表样本。
- 连通分量数只作描述；clDice也不保证没有错误桥接。没有固定路径算法/标定实测前，不写机器人路径连续或修复质量已改善。

### 8.3 同机效率

R0/E0/E1/E2/E3，另F08参考；GPU空闲、同后端/FP32/batch1、400和480方形输入。每模型预热100次，同进程交错5轮×100次同步计时，顺序固定轮换；统计每轮P50/P95和配对比值、样本CV，并记录温度/时钟/功率。若配对比值CV>5%，保留波动结果、标为不稳定，不声称已加速；复测属于测量重复，不改架构或删慢轮次。

峰值allocated/reserved显存每模型新进程同输入测量，基线/增量均记录；前向延迟与含IO端到端时间分开。参数减少不等于更快。FLOPs/MACs如有grid_sample/插值/门控漏算必须标partial，不给不完整算量冠以完整GFLOPs；无法可靠覆盖时保持待测。

## 9. 预登记判断门槛：支持、折中或否定

以下绝对差均在0–1量纲，0.002=0.2个百分点，不是相对增长0.2%。主要判断基于四格匹配三seed均值，并列每seed方向、样本SD及成对差。

### 9.1 强“两模块有效＋组合更好”结论

1. M1独立：E1−E0裂缝IoU≥.002，F1≥.001，mIoU不降；P/R/BF1@2每项下降≤.005。
2. M2独立：E2−E0同上，且BF1@2提升≥.010。达不到则不能称细节模块稳定有效。
3. 组合：E3裂缝IoU比E1、E2**各**至少高.001；相对两单项F1/mIoU均不下降，P/R/BF1@2各下降≤.005；还须相对E0通过同等区域改善门槛。
4. 方向一致性明确为：M1、M2各自IoU和F1相对E0的正差，分别至少2/3seed；M2的BF1相对E0正差至少2/3seed；E3相对E1、E2的IoU正差分别至少2/3seed。最小效应幅度与保护门槛按三seed均值验收，不要求每seed都达到同样幅度。列出所有失败seed，不用均值掩盖。三seed仍不足夸大统计显著性，不以多次val筛选声称领域SOTA。
5. 细线Recall/clDice作为机制证据，如退化必须解释；不能只据IoU或BF1宣布长裂缝连通性提升。

### 9.2 交互与实用选择分开

对每seed和三seed均值分别计算：
D1=E1−E0；D2=E2−E0；D3=E3−E0；G=E3−max(E1,E2)；
I=E3−E1−E2＋E0。IoU主分析，BF1/clDice辅助。

组合最好（G>0）不等于正交互；I>0才是在该指标量纲上的超加性。仅当均值I>0且至少2/3seed I>0，才可描述“观察到一致方向的正交互”，仍给幅度/波动，不能称统计证明。I≤0时即使E3最好，也应写收益叠加有折损；若单模块无益而组合有效，写条件性联合收益，不能伪造两个独立正贡献。

最终轻量候选另对**R0/A0**验收：注册/可训练参数均至少减少10%；平均IoU/F1/mIoU各下降≤.002，P/R/BF1各下降≤.005，至少2/3seed满足IoU−.002容差。只过这一关属于轻量非劣候选，不是精度提高或互补证明。若要称超过A0，必须真实均值提高并完整披露波动；与F08的比较也不能省略。

- E3最好且两单项通过：可保留两模块，进一步核必要性。
- E3未超过单项：优先保留简单的单模块，组合保留负结果。
- M1只减参、M2只改善边界但损伤区域：报告折中，不强行写两个精度增益。
- 四格皆不理想：本轮结论为压缩/恢复假设未获支持，不无限叠加第三模块；再由误差证据决定是否调研新方向。
- L01保留为独立损失备选，本轮不联合；任何后续loss联合须另登记匹配母体。

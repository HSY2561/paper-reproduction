# 结果使用边界与待完成事项

本发布包保留当前基准 A0（SegFormer-B0＋width128＋Aligned）及六原始公开模型的已有结果。它是阶段快照，不是全部后续实验已经结束的证明。

## 必须区分的结果

- 验证集用于训练checkpoint选择和候选筛选；test只能在冻结后评价。不要把val的约0.83 mIoU与test的约0.77直接混作一张排名表。
- 历史test已经被观察过。当前多轮val搜索也有选择偏差；多种子不消除该偏差。后续source-frame-disjoint或独立数据验证仍有意义。
- 公开对照采用相同预算和数据划分，但预训练、CE/OHEM、EMA和Windows/WSL后端不同。这是已有配方对照，不能据此把差异全部归因于网络结构。
- 参数量不等于端到端延迟、部署吞吐或显存。PP-LiteSeg含辅助头的总实例化参数已通过精确正式配置、冻结checkpoint完整key匹配后的CPU直接计数核实为8,150,485；历史paddle.flops的8,039,122是eval参与层计数，两者不能混用。部署有效参数仍应另列。旧evaluation-loop ms/image含数据与指标计算，不能当作受控推理速度。

## 边界指标与退出码

旧test脚本使用默认腐蚀外延与近似距离变换。它不等同于当前验证所用“零外延内边界、精确欧氏距离≤2px、全数据集匹配计数”的BF1。主对照表不报告旧BF1；JSON仅以legacy字段保留，不跨口径比较。

PP-LiteSeg正式训练进程退出码未知，不能写成0；其18k完成依据是日志和最终检查点记录。六原始模型的历史test均有退出码0。A0历史test结果和冻结SHA已核验，但本审计未找到单独的历史test进程退出码。已清理的中间训练目录不再视为“文件仍存在”，保留日志、冻结权重及哈希作为证据。

## 当前模型与负结果

A0是当前控制组，原始SegFormer-B0是公开对照。W96/F08、损失候选或其他历史消融不能直接拼接其各自涨点；未训练的组合不得填写性能。失败配置保留在消融结果中，不能因验证较弱删掉公开模型对照。此前有利的单seed值不能替代多种子门槛结论。

## 可支持与不可支持的论文表述

可描述：在本项目Crack500划分、预算和已披露训练配方下，A0提供较小的参数量及相应的精度取舍；完整报告保留了消融和负结果。

不能描述：领域SOTA、所有指标都最优、参数在所有模型中最少、已证明加速、已解决阴影/落叶场景误检或已验证机器人修复效果。Fast-SCNN参数小于A0，OCRNet的历史test裂缝IoU/F1高于A0；场景和实机结论需要单独实验。

发布文件不包含完整数据集、独立原图文件、训练权重、环境或个人绝对目录；固定24张科学对照面板包含公开基准代表性输入裁图及派生结果。来源路径是原工作区相对标识；复现实验需取得相应数据许可、使用独立的DATA_ROOT并遵守公开源码许可证。

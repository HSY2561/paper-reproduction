# 后续任务与放行规则

后续结构改进母体固定为 **A0 = SegFormer-B0 + width128 + Aligned**。F08、W96、L01都是相对于母体的独立实验，不能在没有联合训练回执时把收益相加。

## 当前顺序

1. 已完成B0 seed42共同初始化补控及真实18k退出、普通/EMA验证选模、冻结SHA；继续保留原始与新控制的来源区分。此前旧B0 seed42二进制初始化证据不完整，推理复现不能补上该历史缺口。
2. 当前20配置和4个额外种子已完成。保留F08精度均值通过、W96完整门槛失败的结论；不为了让轻量模型入选而改比较母体或容差。
3. 按登记顺序完成冻结候选及六个原始公开模型的同后端统一val/test。已经完成的合法公开训练直接复用，不因验证结果弱而删行。
4. 报告参数、前景P/R/F1/IoU、两类mIoU、精确2px边界F1、同机延迟与显存。当前参数节省不能代替速度收益；交错测速波动以及较慢结果必须保留。
5. 最终结果生成后，更新本仓库当前状态、表格、图和复现索引。现有历史test表不预填候选最终测试结果。

## 若继续做轻量化

本轮直接替换A0的512→128融合矩阵。该单层只有65,536个卷积权重，约占A0总参数1.89%，减参上限有限。已尝试的轻量融合还先把多尺度特征恢复到高分辨率，因此减少拼接不等于消除了所有高分辨率激活。

下一轮应先登记新的单变量问题：能否在各尺度原生分辨率完成投影或压缩，再逐级融合，以降低激活和访存成本。需要同时验证细裂缝Recall、边界和延迟，不能只按总参数排名。当前没有授权本仓库脚本自动启动新一轮搜索。

若考虑L01与F08组合，须单独登记A0、仅L01、仅F08、F08+L01的归因表，并完整训练与匹配种子复核。当前结果只支持二者各自的贡献，不支持组合收益。

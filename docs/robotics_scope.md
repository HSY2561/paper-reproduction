# 论文主线与机器人阶段

论文围绕道路裂缝识别、路径生成和精确修复展开。视觉主线先确定公开轻量基线，再根据问题选择改动，完成单项消融、匹配种子和公开模型对照，最后连接真实机器人验证。借鉴参考论文的论证顺序，实际网络和结果以本项目回执为准。

本项目机器人包含四轮移动底盘和笛卡尔三轴修复机构。视觉分割输出供巡检与修复共用；底盘承担工作区移动，三轴机构承担局部精定位。当前仓库的视觉结果不能代替这些机械任务的实测。

后续依次完成：

1. 相机内外参与相机—底盘—三轴坐标标定，验证像素到物理坐标的误差。
2. 分割掩码到中心线/修复轨迹的转换，记录细裂缝漏检和断裂对轨迹的影响。
3. 底盘跟踪和停止定位，记录横向误差、重复定位及任务耗时。
4. 三轴精定位、裂缝宽度误差与定点修复实验。
5. 修复覆盖率、漏修、过修和施工效率评估。所有指标定义、单位及人工真值来源须在实验前固定。

机器人运动学、喷嘴尺寸和控制接口以实际硬件与标定记录为准。当前仓库不宣称已完成闭环修复、墙面吸附或实际施工实验，也不将视觉验证集F1等同为修复覆盖率。

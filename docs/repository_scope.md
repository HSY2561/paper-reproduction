# 本次仓库整理范围

本仓库发布当前A0主线的必要复现代码、配置、小型结果表与图。当前结论以带快照时间的README、状态JSON和结果文档为准。

工作树移除了旧BiSeNetV2/C4和SCSegamba运行中进度、过时服务器队列、重复报告、临时远程脚本、不完整的旧vendor副本、原始图片和无关演示材料。历史提交保留，不重写已有Git历史。

失败实验没有从结果表中抹去。旧结构和损失的完整汇总表继续保留，用于复盘、论文消融和避免重复试错；未把旧方法视为当前基准。2026-10-25本地清理移除了266个淘汰/重复文件，约8.3053 GiB，保留了正式控制、有效独立备选与当前工作流依赖。该本地清理不等于删除所有模型的历史实验结果。

数据集、模型权重、环境、进程状态、密钥、训练大日志、各轮重复源码和大型压缩包不上传。权重通过SHA与选模元数据索引；需要复评被清理的淘汰模型时，必须依据原配置重新训练。

`.gitignore`按顶层目录白名单发布，避免本地遗留的完整源码镜像、数据和临时文件再次被误加入。新增顶层发布目录时，应明确加入白名单；现有`configs/docs/results/scripts/overlays`等目录内可正常协作。

公开副本中的机器专用绝对路径替换为参数或相对来源标识。本地原始证据保留；本仓库的精简审计不是原始日志的完整替代品，也不把运行中的任务注册或进程存在当作训练成功证据。

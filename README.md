## 最新训练结果

Wave6 已完成 **14 个新训练组：12 种模块、2 个解码器宽度对照**，另有原始 SegFormer-B0 冻结基线。各完成组保留 18,000 iter 训练日志、真实退出码、验证结果、逐图指标和选模记录。

| 配置 | 裂缝 IoU（%） | F1（%） | mIoU（%） | 参数量（M） |
|---|---:|---:|---:|---:|
| 原始 SegFormer-B0 | 67.817 | 80.823 | 82.802 | 3.715170 |
| W128 宽度对照 | 67.653 | 80.706 | 82.678 | 3.451746 |
| W128 + Aligned | 67.852 | 80.847 | 82.818 | 3.470434 |
| W128 + GloRe | 67.756 | 80.779 | 82.745 | 3.498978 |

以上是 **Crack500 验证集、单 seed 筛选结果**。Aligned 的区域指标略高于原始 B0，但边界 F1 较低，尚不能证明稳定提升；延迟需统一条件复测。当前没有候选通过预注册的精度线或最终目标线，联合模型、多种子及本轮六个公开模型的统一 test 对照尚未完成。

SE 在 2026-10-17 17:49:47 超时退出（`exit_code=1`，`needs_review`），最后日志为 3200/18000；PSP 在反向 smoke 阶段失败。两者都没有正式性能结果，不能当作完成项。

## 仓库整理与复现说明

当前目录保留最新说明及仍有用的论文、实验材料；被替代的旧草稿和自动生成的时间戳副本已取消跟踪，本地仍保留。此前已发布的版本可从 [Git 历史](https://github.com/HSY2561/paper-reproduction/commits/main) 查看。历史实验的原始代码、配置、失败/中断记录和结果保留，作为对照与可追溯证据，不与本轮结果混用。

最新训练源码在 `experiments/segformer_balance_wave6_20261016/src/PaddleSeg-2.10.0/`。复现前阅读该波次 README 和 `provenance/RUNTIME.md`，按自己的机器调整 Python、数据及权重路径；旧波次使用各自的配置和源码版本。

数据集、训练权重、环境缓存和本机进程锁不上传；权重选模记录与 SHA256 保留。`MANIFEST.md` 和 `manifest_paths.json` 中的实验登记可能包含这些本地文件，不代表每个文件都托管在 GitHub。所有日志、heartbeat 和状态文件均是提交快照，查看最新状态时应以时间戳和退出回执为准。

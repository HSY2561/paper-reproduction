## 目录说明

- `experiments/`：按波次整理的实验配置、日志、指标、逐图诊断和可复核结果。
- `analysis/`：论文复现分析、原论文阅读材料和结构图。
- `figures/`：论文图示源文件（Markdown/Mermaid）。
- `references/`：与 SegFormer 和机器人裂缝覆盖修复相关的文献、开源算法源码及阅读材料。
- `PaddleSeg-release-2.8/`：实验所需的 PaddleSeg 核心代码、裂缝模型、配置和实验脚本。
- 根目录的 `*.yml`、`*.py`：当前实验的模型配置与运行辅助脚本。
- 根目录及各中文 Markdown：实验计划、阶段总结、诊断报告和论文规划。

## 数据与权重

数据集、本地 Python 环境、训练权重和缓存文件不纳入仓库；对应路径和获取方式记录在实验报告中。这样 GitHub 中保留的是代码、配置、日志、指标和论文材料，其他人可以据此了解当前进度并复现实验流程。

## 复现入口

1. 安装 `PaddleSeg-release-2.8/requirements.txt` 中的依赖，并准备 Crack500 数据集。
2. 先阅读 [`当前全部实验结果汇总_20261008.md`](当前全部实验结果汇总_20261008.md) 了解统一协议和当前结论。
3. 根据 `experiments/` 中对应波次的配置、日志和报告复现实验；模型训练入口位于 `PaddleSeg-release-2.8/tools/` 和仓库根目录脚本。
